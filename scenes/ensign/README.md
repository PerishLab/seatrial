# Ensign and Runseal federation

The two optional cases consume verified RC Ensign (CLI and API) and Runseal
artifacts. The first-party Images runtime follows Plumb stable. Pins are channel
configurations, never fixed release markers. Select `ensign-actual` and
`ensign-claims` with this directory's pins.toml. A local --scenes override is
explicit development evidence; formal consumption resolves the published Depot
catalogue and records its complete binding.

The actual case bootstraps one new file estate using documented artifact
commands, then serves the distributed API. Sudo, signing and consumer artifacts
use separate labelled volumes; serve never mounts sudo. An in-lane loopback
relay is the explicitly declared source alias while the canonical HTTPS issuer
remains independent. Real CLI signup/login and public Runseal federation verify
stable external subjects and audience tokens. Barred/ended actors and revoked
login custody cannot acquire another token. Already-issued JWT revocation is
not claimed. Unexpected results fail the case.

The claims case owns an independent inert HTTP issuer and ephemeral P-256 key.
It drives the real Ensign CLI login and Runseal public client surface. Correctly
signed wrong issuer/subject/audience/purpose/expired/future tokens and changed
signatures must refuse. Multi-audience tokens, exposed login-file modes and
network replay from offline recovery are checked. The fixture issuer is not a
second Ensign implementation or evidence of actual Ensign/cloud compatibility.
Neither case parses or exports held login bearers or Runseal private state.

Both cases use fresh labelled lane volumes, no host ports, production credentials,
provider endpoints, STS dispatch or cloud mutation. Result summaries contain only
assertion names and safe counters. The runner must record exact product versions,
commits/seals/archive digests, scene generation, runtime image and full cleanup.
Actual Alibaba acceptance of access-token/ES256 shape, issuer reachability,
provider/role trust and permissions remain Runseal207 operational qualification.
